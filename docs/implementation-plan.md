### V2-T03：桌面角色、托盘与字幕集成

目标：无需浏览器小窗口即可使用爱弥斯，并给出“首批可用”的双窗口集成验收结论。关联 V2-06–V2-08；依赖 V2-T01 公共接口，可与 V2-T02 并行。

范围：Electron 窗口／托盘、客户端角色路由、音频任务与字幕组件，形成可复放前端补丁。只允许角色窗口持有桌面会话与音频设备；管理窗口独立开关。修复缺模型导致音频提前退出的依赖。按显示器工作区域定位，字幕单行分段，音频片段驱动、打断立即停止旧内容。v3 追番、动作生成不在范围内。

验收：Windows 构建产物可启动；右下角与任务栏关系正确，拖动缩放、穿透、隐藏与托盘恢复正常；关闭管理窗口继续对话；双窗口无重复收音／播放／回执；无模型、加载失败、课堂、TTS 失败、打断和重连时字幕／语音正确；显示器与缩放变化后角色可见。需真实桌面运行证据，浏览器成功不能代替。**集成出口**：在 V2-T02 完成后共同回归 R1、R2 两条场景，作为首批可用的验收依据；该项依赖 V2-T02 的完成，未通过时不得宣布首批交付。
